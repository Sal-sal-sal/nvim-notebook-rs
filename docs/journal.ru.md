# Журнал обращений к Colab

В открытом notebook нажми `<leader>ccj`: leader, затем `c`, `c`, `j`.
При leader, назначенном на пробел, это `Space c c j`.
Из любого буфера журнал можно открыть командой `:NotebookColabJournal`.

## Что записывается

Журнал общий для всех notebook и хранит последние 100 запросов расширения к Colab.
Новые записи показаны сверху.
Для каждой записи видны время, операция, длительность, исходный запрос в секции `REQUEST` и ответ в секции `RETURN`.
Записываются выполнение ячеек через Colab, подключение, создание и проверка сессии, установка пакетов и операции с файлами.
Автоматические проверки соединения тоже попадают в историю.
Локальное выполнение Python, сохранение notebook и чтение самого журнала в неё не попадают.
Интерактивный терминал `:NotebookColabLogin` обслуживается отдельно и не записывается в журнал.

`OK` означает успешный ответ.
`ERROR` означает ошибку запроса или выполнения Python, даже если CLI завершился с кодом 0.
`RUNNING` появляется сразу после отправки запроса, до получения ответа.
Если процесс расширения завершился, не записав ответ, останется запись `INTERRUPTED`.
Такой результат не выдаётся за успешное выполнение.

## Как смотреть

- `j`, `k`, `Ctrl-f`, `Ctrl-b` и `/` работают как в обычном буфере.
- `Enter` сворачивает или раскрывает запись.
- `r` перечитывает историю, в том числе во время выполнения долгой ячейки.
- `q` закрывает журнал и возвращает в окно, из которого он был открыт.

Последняя запись раскрыта сразу, более ранние записи свёрнуты.
Буфер доступен только для чтения и не изменяет код notebook.
Содержимое изображений в просмотре заменено кратким описанием размера, чтобы base64 не занимал весь экран.
В файле журнала остаются полные параметры и ответы, включая структурированные результаты и изображения.

## Где хранится

По умолчанию файл находится в `vim.fn.stdpath("state") .. "/notebook-rs/colab-journal.json"`.
Его точный путь показан в начале журнала.
История сохраняется после закрытия Neovim; при появлении 101-й записи самая старая удаляется.
Одновременная запись из нескольких процессов защищена блокировкой, а файл обновляется атомарно.
На macOS и Linux файл создаётся с правами `0600`.

При необходимости задай другой путь до первого обращения к расширению:

```lua
vim.env.NVIM_NOTEBOOK_COLAB_JOURNAL = "/absolute/path/colab-journal.json"
```

Журнал отражает обращения с момента установки этой функции; прежние запросы восстановить нельзя.
