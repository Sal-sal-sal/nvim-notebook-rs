# Документация библиотек без установки тяжёлого окружения

Расширение автоматически готовит локальные подсказки для импортируемых библиотек, которых нет в Python-окружении анализа.
Это работает в notebook с подключённым Pyright.
Например, после `from transformers import pipeline` появляются параметры `pipeline(...)`, документация при наведении и подсказки для возвращаемых объектов с известными типами.

## Как пользоваться

1. Открой `.ipynb` в Neovim и добавь импорт библиотеки.
2. Сделай небольшую паузу после ввода или выйди из режима вставки.
3. Дождись сообщения `Library documentation ready` при первой загрузке.
4. Введи `pipeline(` для подсказки аргументов или нажми `K` на имени функции для документации.

Автоматическое всплывающее окно параметров зависит от настройки твоего плагина дополнения, например `signature.enabled = true` в blink.cmp.
Сам Pyright также отвечает на обычные LSP-запросы hover и signature help.
Перезапускать Neovim после загрузки документации не требуется.

`:NotebookLibraryDocs` принудительно обновляет документацию импортов текущего notebook и позволяет повторить неудачную загрузку.
Без этой команды уже подготовленный кэш используется повторно без обращения к сети.

## Что именно скачивается

Расширение получает метаданные пакета с PyPI и выбирает wheel в пределах установленного лимита.
Если основной пакет слишком большой, оно ищет отдельный пакет `types-имя` или `имя-stubs`.
Зависимости пакета не скачиваются.
`pip install`, установочные скрипты и импорт кода загруженной библиотеки не выполняются.

Из wheel сохраняются готовые `.pyi` или статические интерфейсы, построенные из исходников Python: импорты, объявления классов, сигнатуры, аннотации и docstring.
Тела функций, бинарные модули и веса моделей в кэш не попадают.
Архив wheel используется временно и после обработки удаляется.
Целостность загрузки проверяется по SHA-256 из метаданных PyPI.

В проверке с `transformers 5.22.2` был скачан один архив размером около 13 МБ, без Torch, TensorFlow, tokenizers и моделей.
В кэше остались интерфейсы и документация, а библиотека `transformers` не была установлена в окружение анализа.

Установленные локальные библиотеки и модули проекта имеют приоритет.
Документация не меняет выбранный runtime: для выполнения кода библиотека должна быть установлена локально или в Colab.

## Настройка

По умолчанию автозагрузка включена, а лимит одного архива равен 25 МБ:

```lua
require("notebook_rs").setup({
  python_lsp = {
    documentation = {
      auto_download = true,
      max_download_mb = 25,
      packages = {
        transformers = "transformers==5.22.2",
      },
    },
  },
})
```

Таблица `packages` сопоставляет имя в `import` с именем пакета PyPI и необязательной версией.
Если запись отсутствует, используется имя импорта и актуальная стабильная версия пакета при первой загрузке.
Для `sklearn`, `PIL`, `yaml` и `cv2` уже настроены соответствия `scikit-learn`, `Pillow`, `PyYAML` и `opencv-python`.
Для Colab лучше указать версию, совпадающую с `transformers.__version__` в удалённом runtime.

`auto_download = false` отключает автоматические обращения к сети.
Существующий кэш и ручная команда `:NotebookLibraryDocs` продолжают работать.
Параметр `cache = "/absolute/path"` внутри `documentation` задаёт другой каталог кэша.
По умолчанию используется `stdpath("cache")/notebook-rs/library-docs`.
Кэш отделён от notebook и Python-окружения; исходный код и результаты ячеек не меняются.

## Ограничения

Для библиотеки без подходящего wheel или stubs в пределах лимита загрузка завершается сообщением с причиной.
Большой runtime автоматически устанавливаться не будет.
Сгенерированные интерфейсы сохраняют существующие аннотации, но не восстанавливают все типы из тел функций.
Поэтому динамические API и библиотеки с бинарными расширениями могут давать неполные подсказки.
Готовые официальные stubs или установленная библиотека обычно точнее.

Механизм использует поддержку [type stubs](https://github.com/microsoft/pyright/blob/main/docs/type-stubs.md) и [дополнительных путей анализа](https://github.com/microsoft/pyright/blob/main/docs/settings.md) в Pyright.
