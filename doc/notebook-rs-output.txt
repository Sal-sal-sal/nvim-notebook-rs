*notebook-rs-output.txt*  Navigating cell output

OUTPUT                                               *notebook-rs-output*

Enable textual inline output navigation: >lua
    require("notebook_rs").setup({
      cells_output_interacteable = true,
      nootbook_result = "nootbook",
    })
<
The default for cells_output_interacteable is false.
The exact interacteable spelling is part of the configuration API.

When enabled, text results and tracebacks become real buffer lines below
that cell, with display prefixes concealed by Neovim.
Use j/k, h/l, Ctrl-f/Ctrl-b, /search, and visual selection normally.
Yanking only output strips the display prefixes from the register.
Source cursor positions and the viewport remain stable during redraws.
Output rows are protected from direct edits.
Edit and rerun the source cell to change its result.
Running or editing a cell while in its output targets that source cell.
Source undo and redo remain available.

Cell output remains structured notebook data when saving with :write.
Display rows are excluded from Python execution and stored source.
Changing source clears its stale output while retaining other cells.
Images and HTML remain virtual media placeholders; use
:NotebookOpenArtifact to open generated artifacts.

Set cells_output_interacteable = false to restore virtual text output.
It affects only nootbook_result = "nootbook"; "window" and "hidden"
retain their existing display behavior.
Re-running setup changes the mode in open notebooks.
Start a new Neovim session after updating plugin source files.

See |notebook-rs-options| and |notebook-rs-keys| for other settings and keys.
A Russian walkthrough is available at docs/guide.ru.md in the repository.
